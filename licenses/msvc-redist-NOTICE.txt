The Windows archive carries Microsoft Visual C++ runtime DLLs that the Swift runtime loads, for
example vcruntime140.dll, vcruntime140_1.dll, msvcp140.dll and concrt140.dll. They come from the
Swift for Windows runtime directory (%LOCALAPPDATA%\Programs\Swift\Runtimes\<version>\usr\bin),
which ships them beside the Swift DLLs. As of swift_tar 0.1.0 they are version 14.42.34433.0.
