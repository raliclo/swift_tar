swift_tar 0.2.0 is the public build (no LZFSE). Its behaviour is the same as 0.1.5: no source file and no codec or libarchive pin changed. What changed is how it is built, named and shipped.

swift_tar 0.2.0 是公開版（不含 LZFSE）。行為與 0.1.5 相同：沒有任何原始碼檔案、也沒有任何 codec 或 libarchive 的 pin 改變。改變的是建置、命名與出貨方式。

## Archives / 封存

One `.tar.zst` per platform, each with a `.sha256` beside it:

| platform | notes |
|---|---|
| `linux-x86_64-musl`, `linux-aarch64-musl` | fully static against musl; needs nothing on the target |
| `macos-x86_64`, `macos-arm64` | links the system's Swift runtime |
| `windows-x86_64`, `windows-arm64` | carries its Swift runtime DLLs |

每個平台一份 `.tar.zst`，旁邊各附 `.sha256`。Linux 版對 musl 完全靜態連結，目標機器上什麼都不需要；macOS 版連結系統的 Swift runtime；Windows 版附帶 Swift runtime DLL。

## Changes since 0.1.5 / 與 0.1.5 的差異

- **The Linux archives are renamed.** `swift_tar-<version>-linux-<arch>.tar.zst` is now `swift_tar-<version>-linux-<arch>-musl.tar.zst`. It is the same static musl build as before; a script or URL that names the old file must be updated. There is no glibc build: one would need a glibc at least as new as the build machine's.
  **Linux 封存改名。** `swift_tar-<版本>-linux-<arch>.tar.zst` 改為 `swift_tar-<版本>-linux-<arch>-musl.tar.zst`，內容與之前同樣是靜態 musl 版；寫死舊檔名的腳本或網址需要更新。沒有 glibc 版：它需要不比建置機器舊的 glibc。
- **Two new platforms:** `macos-x86_64` and `windows-arm64`.
  **新增兩個平台：** `macos-x86_64` 與 `windows-arm64`。
- **Built by GitHub Actions** with Swift 6.4.2 (0.1.5 was built on the maintainers' machines with 6.4.0 and 6.4.1), and every archive has a build-provenance attestation:
  **改由 GitHub Actions 建置**，使用 Swift 6.4.2（0.1.5 是在維護者的機器上以 6.4.0 與 6.4.1 建置），每份封存都帶有建置來源證明（attestation）：

  ```sh
  gh attestation verify swift_tar-0.2.0-linux-x86_64-musl.tar.zst -R raliclo/swift_tar
  ```

- **The macOS binary is stripped**, as the others already were (0.1.5's arm64 binary kept about 3,000 local symbols; stripped it is 1,724,640 bytes instead of 1,968,888).
  **macOS 執行檔已 strip**，與其他平台一致（0.1.5 的 arm64 執行檔保留約 3,000 個本地符號；strip 後由 1,968,888 降為 1,724,640 bytes）。
- **`install.zsh`** installs the release for the machine it runs on into `~/.local/bin` (or `--prefix`), after checking its `.sha256` and that it reports the version asked for: `zsh install.zsh 0.2.0`.
  **`install.zsh`** 會為執行它的機器安裝對應的正式版到 `~/.local/bin`（或 `--prefix`），安裝前核對 `.sha256` 並確認它回報的是所要求的版本：`zsh install.zsh 0.2.0`。

## Install / 安裝

```sh
brew install raliclo/swift_tar/swift_tar        # macOS arm64
scoop install raliclo/swift_tar                 # Windows x86-64
zsh install.zsh 0.2.0                           # any of the six
```
