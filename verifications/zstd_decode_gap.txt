=== 判讀 / how to read this ===
  user 相同、sys 不同    → 計算量相同，差在系統呼叫；平行化不會有幫助
  user 不同              → 計算量本身有差
  CPU/wall 明顯不同       → 才是平行度的差異
  RAM disk 與磁碟結論不同 → 該差距屬於儲存層，不屬於 codec
  same user, different sys -> same computation; parallelising will not close it
  different user           -> the computation itself differs
  different CPU/wall       -> only then is it about parallelism
  RAM disk and disk disagree -> the gap belongs to storage, not to the codec
